# Клетка — как устроена лаборатория

Каждая лаборатория — отдельный файл `js/labs/<id>.js`, подключённый в `index.html` тегом `<script defer>` до `js/app.js`. Файл — обычный скрипт (ES5-стиль, как `js/app.js`: `var`, `function`, без модулей, без import/export, без сборки), работает при открытии `index.html` с диска.

```js
/* Лаборатория «…» — одна строка о назначении. */
(function () {
  'use strict';
  var KL = (window.KL = window.KL || {});
  KL.labs = KL.labs || {};
  KL.labs.periodic = {
    title: 'Таблица Менделеева',          // заголовок в рамке и на карточке
    icon: 'Fe',                           // 1–4 символа, моноширинный шрифт на карточке
    desc: 'Короткое описание для карточки, до 90 символов',
    long: 'Развёрнутое описание 1–2 предложения для отдельной страницы лаборатории',
    subjectName: 'Химия',
    mount: function (el) { /* строит интерфейс внутри el */ }
  };
})();
```

## Жизненный цикл

- `mount(el)` вызывается, когда `el` (это `.lab-body`) **ещё не вставлен в документ**: `el.clientWidth === 0`. Первую отрисовку canvas делайте через `ResizeObserver` на canvas (он сработает, когда элемент получит размер) или `requestAnimationFrame`. `ResizeObserver` нужен в любом случае — для смены ширины окна.
- Одна и та же лаборатория может быть смонтирована дважды (в теории и на отдельной странице) — никакого глобального состояния, никаких фиксированных `id` в разметке.
- При уходе со страницы элемент просто удаляется из DOM. Подписки на `window`/`document` снимайте, когда `el.isConnected === false` (проверяйте в обработчике), анимации (`requestAnimationFrame`) останавливайте так же.
- Тема: при смене светлой/тёмной темы на `window` приходит событие `kl-theme`. Цвета canvas берите из CSS-переменных в момент рисования: `getComputedStyle(document.documentElement).getPropertyValue('--ink')`.

## Оформление

Используйте переменные: `--ink` (основной синий), `--red`, `--ok`, `--warn`, `--text`, `--muted`, `--line`, `--sheet`, `--sheet-2`, `--paper`, `--grid`, `--grid-strong`, `--ink-soft`, `--red-soft`, `--ok-soft`, `--warn-soft`, шрифты `--f-body`, `--f-mono`, `--f-display`, `--f-hand`. Цвета предметов: `--s-chemistry` и т. п.

Готовые классы (`css/app.css`): `.lab-row` (строка контролов), `label` / `label.inline`, `input[type=range|text|number]`, `select`, `.btn`, `.btn.sm`, `.btn.primary`, `.btn.ghost`, `.chip`, `.chip.ink|ok|red|warn`, `.seg` + `button.on` (переключатель), `.readout` (сетка показаний: `<div><b>12,5 м</b><span>дальность</span></div>`), `.lab-note`, `.tbl` (таблица), `.score-row`, `.game-word` (кнопки-буквы), `.punnett`, `.ratio-list`, `.pt-*` (таблица Менделеева), `.muted`, `.mono`, `.hand`, `.sr`.

Собственные стили лаборатории — один раз вставьте `<style id="lab-<id>-css">` в `document.head` из самого файла (проверьте, что его ещё нет). Все селекторы начинайте с уникального префикса (`.lb-sun-…`), в CSS используйте только переменные темы — тогда тёмная тема работает сама. Файл `css/app.css` не редактируйте.

## Требования к качеству

- Работает с мыши, пальца и клавиатуры; у всех контролов есть подписи (`label` или `aria-label`), фокус виден.
- Ширина 320–1200 px без горизонтальной прокрутки страницы (широкие таблицы — в обёртке с `overflow-x:auto`).
- Числа — с десятичной запятой по-русски (`toLocaleString('ru-RU')` или замена точки).
- Формулы можно выводить через `KL.app.renderMath(el)` (KaTeX, разделители `$…$`) — вызывайте после вставки HTML; `KL.app` доступен во время работы.
- Фактическая точность обязательна: все данные (даты, формы глаголов, ударения, массы элементов) сверены с надёжными источниками.
- Нет ошибок в консоли. Нет внешних запросов и библиотек.
