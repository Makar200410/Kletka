# Клетка — формат контента

Каждый предмет лежит в своём файле `js/data/<id>.js` и регистрируется вызовом `KL.addSubject({...})`.
Файл — обычный JavaScript (не модуль, без import/export), подключается тегом `<script>` и работает даже при открытии `index.html` с диска.

Проверка файла:

```bash
node tools/validate.js js/data/chemistry.js
```

Валидатор проверяет структуру, уникальность id, корректность ответов, парность тегов HTML и знаков `$`.

---

## 1. Предмет

```js
KL.addSubject({
  id: 'chemistry',                // латиницей, совпадает с именем файла
  name: 'Химия',
  tagline: 'От строения атома до цепочек превращений',   // одна строка, до 70 символов
  exams: {
    oge: {
      title: 'ОГЭ по химии',
      tasks: 23,                  // число заданий в варианте
      time: '3 ч',                // длительность
      maxPrimary: 38,             // максимальный первичный балл
      structure: 'Часть 1 — 19 заданий с кратким ответом. Часть 2 — 4 задания с развёрнутым ответом, из них 2 — реальный эксперимент.',
      tip: 'Главный совет по экзамену одной-двумя фразами.'
    },
    ege: {
      title: 'ЕГЭ по химии',
      tasks: 34, time: '3 ч 30 мин', maxPrimary: 56,
      minScore: 36,               // минимальный тестовый балл (необязательно)
      structure: '...',
      tip: '...'
    }
  },
  topics: [ /* темы, см. ниже */ ],
  cards: [ /* флеш-карточки, см. ниже */ ]
});
```

Если у предмета нет ОГЭ или ЕГЭ в нужном виде, всё равно заполните оба блока (для математики ЕГЭ — профильный уровень).

## 2. Тема

```js
{
  id: 'chem-atom',                // префикс предмета + slug, уникален во всём проекте
  title: 'Строение атома',
  exam: ['oge', 'ege'],           // к каким экзаменам относится тема
  refs: { oge: '1', ege: '1' },   // номера заданий в КИМ (строкой, можно '1–3'); ключ опускается, если темы нет в этом экзамене
  level: 1,                       // сложность темы 1..3
  minutes: 15,                    // время чтения теории
  summary: 'Одна фраза: о чём тема и зачем она на экзамене.',
  keyPoints: [                    // 4–6 пунктов шпаргалки, коротко
    'Число протонов = порядковый номер Z',
    '...'
  ],
  theory: [                       // 3–6 разделов
    { h: 'Из чего состоит атом', html: String.raw`<p>...</p>` },
    ...
  ],
  tasks: [ /* 9–12 заданий */ ]
}
```

### Как писать теорию

Теория — это HTML-строка. Всегда используйте шаблонную строку `String.raw\`...\``, тогда обратные слэши LaTeX не нужно экранировать. Внутри нельзя использовать обратную кавычку ` и последовательность `${`.

Доступные элементы оформления:

| Разметка | Как выглядит |
|---|---|
| `<p>`, `<ul>`, `<ol>`, `<b>`, `<i>`, `<sub>`, `<sup>`, `<br>` | обычный текст |
| `<div class="rule">...</div>` | рамка с главным правилом или формулой |
| `<div class="tip">...</div>` | лайфхак, приём решения |
| `<div class="trap">...</div>` | ловушка экзамена, типичная ошибка |
| `<div class="example"><p><b>Пример.</b> ...</p>...</div>` | разобранный пример |
| `<table class="tbl"><tr><th>..</th></tr><tr><td>..</td></tr></table>` | таблица |
| `<details><summary>Подробнее</summary>...</details>` | раскрывающийся блок |
| `<span class="hl">...</span>` | выделение маркером |
| `<div class="quick" data-a="ответ|вариант">Вопрос?</div>` | мини-проверка прямо в теории: поле ввода и кнопка «Проверить». Варианты ответа через `|` |
| `<div class="lab-embed" data-lab="periodic"></div>` | встроенная интерактивная лаборатория (список ниже) |
| `$...$` и `$$...$$` | формула LaTeX (KaTeX), строчная и выключная |

Встраиваемые лаборатории (`data-lab`): `periodic` (таблица Менделеева), `graph` (графики функций с параметрами), `projectile` (бросок под углом к горизонту), `numsys` (системы счисления), `truth` (таблицы истинности), `stress` (тренажёр ударений), `timeline` (хронология истории России), `punnett` (решётка Пеннета), `verbs` (неправильные глаголы), `sun` (высота Солнца и поясное время).

Химические формулы пишите через `<sub>`/`<sup>`: `H<sub>2</sub>SO<sub>4</sub>`, `Fe<sup>3+</sup>`. Стрелки: `→`, `⇄`. Для физики и математики — LaTeX.

Хорошая теория: коротко, по делу, с опорой на то, как тема проверяется на экзамене. В каждой теме минимум один `rule`, один `trap`, один `example` и одна `quick`.

## 3. Задание

Общие поля:

```js
{
  id: 'chem-atom-1',          // уникален во всём проекте
  type: 'choice',             // choice | multi | input | order | match
  exam: 'oge',                // 'oge' | 'ege' | 'both'
  difficulty: 1,              // 1 базовый, 2 повышенный, 3 высокий
  q: 'Текст условия (HTML, можно $LaTeX$)',
  hint: 'Подсказка без готового ответа',
  solution: 'Подробное решение (HTML, можно $LaTeX$)'
}
```

Для строк с LaTeX в `q`/`solution`/`options` тоже используйте `String.raw\`...\``.

### choice — один верный ответ
```js
options: ['вариант 1', 'вариант 2', 'вариант 3', 'вариант 4'],
answer: 2                   // индекс верного варианта с нуля
```

### multi — несколько верных (формат «запишите номера выбранных ответов»)
```js
options: ['...', '...', '...', '...', '...'],
answer: [0, 3]              // индексы верных вариантов
```

### input — краткий ответ
```js
answer: '12',               // строка; или массив допустимых вариантов ['12', '12,0']
tolerance: 0.01,            // необязательно: допуск для числового ответа
unit: 'м/с'                 // необязательно: единица, показывается после поля
```
Проверка игнорирует регистр, пробелы по краям, различие е/ё, запятую и точку в числах. Для ответа «цифрами без пробелов» (номера, последовательности) указывайте строку цифр: `'2413'`.

### order — расставить по порядку
```js
items: ['первый', 'второй', 'третий', 'четвёртый']   // в ПРАВИЛЬНОМ порядке, сайт перемешает сам
```

### match — установить соответствие
```js
left:  ['формула A', 'формула B', 'формула C'],
right: ['класс 1', 'класс 2', 'класс 3', 'класс 4'],
answer: [1, 0, 3]           // для каждого элемента left — индекс в right
```

В каждой теме: 9–12 заданий, минимум 3 разных типа, задания и на ОГЭ, и на ЕГЭ (если тема есть в обоих), сложность от 1 до 3. Условия должны быть в духе реальных заданий ФИПИ, но придуманы заново (не копируйте тексты из открытого банка дословно).

## 4. Флеш-карточки

```js
cards: [
  { q: 'Лакмус в кислой среде', a: 'Красный' },
  { q: String.raw`Формула ускорения`, a: String.raw`$a = \dfrac{v - v_0}{t}$` }
]
```

20–30 карточек на предмет: определения, формулы, даты, исключения.
