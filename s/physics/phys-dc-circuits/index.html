Цепи постоянного тока: закон Ома, соединения, мощность

Закон Ома для участка и для полной цепи, расчёт смешанного соединения резисторов, мощность и работа тока.

18 мин чтенияОГЭЕГЭ17 заданий

Коротко

главное за 30 секунд
  1. Закон Ома для участка: $I = \dfrac{U}{R}$; сопротивление проводника $R = \rho\dfrac{l}{S}$
  2. Последовательно: $I$ одинаков, $R = R_1 + R_2$; параллельно: $U$ одинаково, $\dfrac1R = \dfrac1{R_1} + \dfrac1{R_2}$
  3. Смешанное соединение «сворачивают» по шагам, а потом «разворачивают» обратно
  4. Полная цепь: $I = \dfrac{\mathcal{E}}{R + r}$; напряжение на клеммах $U = \mathcal{E} - Ir$; ток КЗ $\mathcal{E}/r$
  5. Мощность: $P = UI = I^2R = \dfrac{U^2}{R}$; работа и теплота: $A = Q = I^2Rt$
  6. Наибольшая мощность во внешней цепи — при $R = r$: $P_{\max} = \dfrac{\mathcal{E}^2}{4r}$

1.Закон Ома для участка цепи

Сила тока на участке цепи прямо пропорциональна напряжению и обратно пропорциональна сопротивлению.

$$I = \dfrac{U}{R}, \qquad R = \rho\dfrac{l}{S}$$ Здесь $\rho$ — удельное сопротивление материала, $l$ — длина проводника, $S$ — площадь его сечения.

Вольт-амперная характеристика (ВАХ) резистора — прямая, проходящая через начало координат. Чем круче график $I(U)$, тем меньше сопротивление: $R = U/I$ для любой точки прямой.

На графике $I(U)$ наклон равен $1/R$, а на графике $U(I)$ — самому $R$. Прежде чем определять сопротивление по графику, посмотрите, какая величина отложена по вертикали.
Единицы: если $\rho$ дано в Ом·мм²/м, сечение подставляют в мм², а длину — в метрах. Тогда $R$ получается в омах без пересчётов.
Проверь себя. Напряжение на резисторе 12 В, сопротивление 4 Ом. Чему равна сила тока (в А)?

Ответ: 3

2.Последовательное, параллельное и смешанное соединение

ПоследовательноеПараллельное
Сила токаодинакова: $I = I_1 = I_2$складывается: $I = I_1 + I_2$
Напряжениескладывается: $U = U_1 + U_2$одинаково: $U = U_1 = U_2$
Сопротивление$R = R_1 + R_2$$\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2}$

Для двух резисторов параллельно удобнее $R = \dfrac{R_1R_2}{R_1 + R_2}$; для $n$ одинаковых — $R = R_0/n$.

Алгоритм для смешанного соединения: 1) найдите участки, которые точно параллельны или последовательны, и замените каждый одним резистором; 2) повторяйте, пока не останется один резистор; 3) найдите ток источника; 4) идите обратно и распределяйте токи и напряжения по участкам.

Пример. Резистор $R_1 = 2$ Ом последовательно с двумя параллельными по 4 Ом. Параллельная часть: $2$ Ом, всего $R = 2 + 2 = 4$ Ом. При $U = 12$ В общий ток $I = 3$ А; на параллельной части $U' = 3\cdot 2 = 6$ В; в каждой ветви $I = 6/4 = 1{,}5$ А.

Общее сопротивление параллельного соединения всегда меньше самого маленького из резисторов. Если у вас получилось больше — вы забыли перевернуть дробь.
Проверь себя. Резисторы 12 Ом и 4 Ом соединены параллельно. Чему равно общее сопротивление (в Ом)?

Ответ: 3

3.Закон Ома для полной цепи

Реальный источник тока имеет ЭДС $\mathcal{E}$ (работу сторонних сил по переносу единичного заряда) и внутреннее сопротивление $r$. Ток идёт через внешнюю цепь $R$ и через сам источник.

$$I = \dfrac{\mathcal{E}}{R + r}, \qquad U = IR = \mathcal{E} - Ir, \qquad I_{\text{кз}} = \dfrac{\mathcal{E}}{r}$$ $U$ — напряжение на клеммах источника. Оно равно $\mathcal{E}$ только при разомкнутой цепи ($I = 0$) и уменьшается с ростом тока.

Пример. $\mathcal{E} = 12$ В, $r = 1$ Ом, $R = 5$ Ом. $I = \dfrac{12}{5 + 1} = 2$ А, напряжение на клеммах $U = 12 - 2\cdot 1 = 10$ В.

Вольтметр, подключённый к клеммам, показывает $U = \mathcal{E} - Ir$, а не $\mathcal{E}$. Чем меньше сопротивление нагрузки и чем больше ток, тем сильнее «проседает» напряжение.
Неизвестные $\mathcal{E}$ и $r$ находят из двух режимов: $\mathcal{E} = I_1(R_1 + r) = I_2(R_2 + r)$ — получается уравнение с одной неизвестной $r$.
Проверь себя. $\mathcal{E} = 12$ В, $r = 1$ Ом, $R = 5$ Ом. Найдите силу тока (в А).

Ответ: 2

4.Мощность и работа тока

Работа тока на участке $A = UIt$. Мощность — работа за единицу времени.

$$P = UI = I^2R = \dfrac{U^2}{R}, \qquad Q = I^2Rt$$ Формулу для мощности выбирают по тому, что постоянно: при последовательном соединении одинаков ток — удобно $I^2R$; при параллельном одинаково напряжение — удобно $U^2/R$.

Мощность во внешней цепи зависит от $R$: при малом $R$ ток велик, но напряжение на нагрузке мало; при большом $R$ мало уже сам ток. Максимум — когда $R = r$.

Пример. Лампа 220 В, 100 Вт: сопротивление $R = \dfrac{U^2}{P} = \dfrac{220^2}{100} = 484$ Ом. Ток $I = \dfrac{P}{U}\approx 0{,}45$ А.

Если две одинаковые лампы включить последовательно в сеть, на каждой будет вдвое меньшее напряжение и вчетверо меньшая мощность (яркость). Формулу $P = U^2/R$ можно применять только для одной и той же лампы — с её настоящим $U$.
Проверь себя. Через резистор сопротивлением 10 Ом идёт ток 5 А. Какая мощность выделяется в резисторе (в Вт)?

Ответ: 250
