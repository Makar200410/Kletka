Неметаллы: галогены, сера, азот, углерод

Свойства простых веществ и главных соединений галогенов, серы, азота, углерода и кремния: какие реакции идут и почему.

20 мин чтенияОГЭЕГЭ21 задание

Коротко

главное за 30 секунд
  1. Окислительная активность галогенов падает от F2 к I2; более активный галоген вытесняет менее активный из соли
  2. Сера: −2 (H2S) → 0 (S) → +4 (SO2) → +6 (H2SO4); H2S — восстановитель, H2SO4 (конц.) — окислитель
  3. Азот: −3 (NH3), 0, +1, +2, +4, +5 (HNO3); NH3 — основание и восстановитель
  4. Нитраты при нагревании: до Mg — нитрит и O2; Mg–Cu — оксид, NO2, O2; после Cu — металл, NO2, O2
  5. CO — несолеобразующий оксид и восстановитель, CO2 — кислотный оксид
  6. Кремний и SiO2 реагируют с растворами щелочей; SiO2 с водой не реагирует

1.Галогены: F, Cl, Br, I

Галогены — элементы VIIA группы, молекулы двухатомные: F2, Cl2, Br2, I2. Внешний уровень ns2np5: до завершения не хватает одного электрона, поэтому это сильные окислители.

Простое веществоСостояние и цветОкислитель
F2бледно-жёлтый газсамый сильный
Cl2жёлто-зелёный газсильный
Br2красно-бурая жидкостьсредний
I2тёмно-фиолетовые кристаллыслабый
Более сильный галоген вытесняет более слабый из раствора его соли: Cl2 + 2NaBr → 2NaCl + Br2; Br2 + 2KI → 2KBr + I2. Обратные реакции невозможны. Фтор в растворах реагирует с водой: 2F2 + 2H2O → 4HF + O2.

Хлор в воде: Cl2 + H2O ⇄ HCl + HClO. В щёлочи: на холоде Cl2 + 2NaOH → NaCl + NaClO + H2O, при нагревании 3Cl2 + 6NaOH → 5NaCl + NaClO3 + 3H2O.

HF — слабая кислота, а HCl, HBr, HI — сильные. Среди галогеноводородов самый сильный восстановитель — HI. Фторид кальция CaF2 в воде нерастворим (в отличие от других галогенидов Ca).
Проверь себя. Какой галоген — самый сильный окислитель?

Ответ: фтор

2.Сера и её соединения

Сера — жёлтое кристаллическое вещество, нерастворимое в воде. Степени окисления: −2, 0, +4, +6. Поэтому сера и её соединения проявляют разные свойства.

  • S (0): окислитель с металлами и водородом (Fe + S → FeS; H2 + S → H2S), восстановитель с кислородом (S + O2 → SO2).
  • H2S (−2): только восстановитель. 2H2S + 3O2 → 2SO2 + 2H2O (избыток O2); 2H2S + O2 → 2S + 2H2O (недостаток).
  • SO2 (+4): кислотный оксид (SO2 + 2NaOH → Na2SO3 + H2O), чаще восстановитель (2SO2 + O2 ⇄ 2SO3), обесцвечивает бромную воду и KMnO4.
  • H2SO4 (+6): сильная кислота; концентрированная — окислитель, обугливает органику, гигроскопична.
Сера в высшей степени окисления (+6) может быть только окислителем, в низшей (−2) — только восстановителем, в промежуточной (0, +4) — и тем и другим.

Пример. Качественная реакция на сульфат-ион: Na2SO4 + BaCl2 → BaSO4↓ + 2NaCl — белый осадок, нерастворимый в кислотах. Для сульфид-иона: Na2S + Pb(NO3)2 → PbS↓ + 2NaNO3 — чёрный осадок.

При разбавлении серной кислоты нужно лить кислоту в воду, а не наоборот. И запомните: SO2 — газ с запахом горящей серы, а SO3 — жидкость, с водой образует H2SO4.
Проверь себя. Какую роль играет сероводород в окислительно-восстановительных реакциях: окислитель или восстановитель?

Ответ: восстановитель

3.Азот и его соединения

Молекула N2 содержит тройную связь и очень прочна, поэтому азот химически инертен. Он реагирует при высоких температурах: N2 + 3H2 ⇄ 2NH3 (катализатор, давление), N2 + O2 → 2NO (электрическая дуга).

Аммиак NH3 (−3): газ с резким запахом, хорошо растворим в воде. Основные свойства: NH3 + HCl → NH4Cl. Восстановитель: 4NH3 + 5O2 → 4NO + 6H2O (Pt), 4NH3 + 3O2 → 2N2 + 6H2O (горение), 2NH3 + 3CuO → 3Cu + N2 + 3H2O.

Соли аммония распознают щёлочью при нагревании: NH4Cl + NaOH → NH3↑ + NaCl + H2O. Разлагаются: NH4Cl → NH3 + HCl; NH4NO3 → N2O + 2H2O; NH4NO2 → N2 + 2H2O.

Оксиды и кислота. NO бесцветный, на воздухе бурый: 2NO + O2 → 2NO2. 4NO2 + O2 + 2H2O → 4HNO3. Азотная кислота — сильный окислитель (см. тему о металлах).

Нитраты при нагревании: металлы до Mg → нитрит + O2 (2KNO3 → 2KNO2 + O2); от Mg до Cu → оксид + NO2 + O2 (2Cu(NO3)2 → 2CuO + 4NO2 + O2); после Cu → металл + NO2 + O2.
Аммиак — единственный газ, который даёт щелочную среду; его нельзя сушить концентрированной H2SO4 или CaCl2 (реагирует). Сушат его оксидом кальция или NaOH.
Проверь себя. Какой газ выделяется при нагревании хлорида аммония со щёлочью?

Ответ: аммиак

4.Углерод, кремний и их оксиды

Углерод — восстановитель: C + O2 → CO2 (избыток O2), 2C + O2 → 2CO (недостаток), C + CuO → Cu + CO, C + H2O → CO + H2. С металлами образует карбиды: 4Al + 3C → Al4C3.

CO — несолеобразующий оксид, ядовит, сильный восстановитель: Fe2O3 + 3CO → 2Fe + 3CO2. CO2 — кислотный оксид: CO2 + Ca(OH)2 → CaCO3↓ + H2O (известковая вода мутнеет). При избытке CO2 осадок растворяется: CaCO3 + CO2 + H2O → Ca(HCO3)2.

Кремний и SiO2 с водой не реагируют, но растворяются в щелочах: Si + 2NaOH + H2O → Na2SiO3 + 2H2↑; SiO2 + 2NaOH → Na2SiO3 + H2O. Кислотой кремниевую H2SiO3 выделяют из силиката: Na2SiO3 + 2HCl → H2SiO3↓ + 2NaCl. С плавиковой кислотой: SiO2 + 4HF → SiF4 + 2H2O.

Пример. Как получить CO2 в лаборатории: CaCO3 + 2HCl → CaCl2 + H2O + CO2↑. Любой карбонат реагирует с сильной кислотой с выделением углекислого газа.

CO2 и SO2 оба мутят известковую воду, но только SO2 обесцвечивает бромную воду и раствор KMnO4 — так их различают.
Проверь себя. Какое простое вещество-неметалл реагирует с раствором щёлочи с выделением водорода: углерод или кремний?

Ответ: кремний
