Расчёты по уравнению реакции: избыток, выход, примеси

Универсальный алгоритм расчёта по уравнению реакции, а также задачи на избыток и недостаток, выход продукта, примеси и состав раствора после реакции.

20 мин чтенияОГЭЕГЭ21 задание

Коротко

главное за 30 секунд
  1. Коэффициенты в уравнении показывают отношение количеств веществ (моль), а не масс
  2. Алгоритм: уравнение → n известного → n искомого по коэффициентам → масса или объём
  3. Избыток и недостаток: считают n каждого вещества, делят на коэффициент; расчёт ведут по недостатку
  4. Выход продукта: η = m(практ.) / m(теор.) · 100%
  5. В реакцию вступает только чистое вещество: m(чист.) = m(смеси) · (1 − ω(примесей))
  6. Масса раствора после реакции = сумма масс исходных веществ − масса осадка − масса газа

1.Базовый алгоритм

  1. Запишите уравнение реакции и расставьте коэффициенты.
  2. Найдите количество вещества известного участника: n = m / M или n = V / 22,4.
  3. Составьте пропорцию по коэффициентам и найдите n искомого.
  4. Переведите n в нужную величину: m = n · M, V = n · 22,4.

Пример. Сколько литров водорода (н. у.) выделится при действии соляной кислоты на 6,5 г цинка?
Zn + 2HCl → ZnCl2 + H2↑
n(Zn) = 6,5 / 65 = 0,1 моль. По коэффициентам n(H2) = n(Zn) = 0,1 моль. V(H2) = 0,1 · 22,4 = 2,24 л.

Отношение количеств веществ равно отношению коэффициентов: n(A) / a = n(B) / b. Массы веществ так соотносить нельзя — только после перехода к молям.
Самая частая ошибка — забыть про коэффициент: например, в 2H2 + O2 → 2H2O из 1 моль O2 получается 2 моль воды, а не 1. Уравнение всегда записывайте с коэффициентами до расчёта.
Проверь себя. Сколько граммов воды образуется при сгорании 4 г водорода (2H2 + O2 → 2H2O)?

Ответ: 36

2.Избыток и недостаток

Если даны количества двух реагентов, один из них может быть в избытке. Продукта получится столько, сколько позволяет вещество в недостатке.

  1. Найдите n обоих реагентов.
  2. Разделите n каждого на его коэффициент в уравнении. Меньшее число — недостаток.
  3. Расчёт продуктов ведите только по недостатку. Остаток избытка = n(избытка) − n, прореагировавшее с недостатком.

Пример. К 8 г NaOH добавили 3,65 г HCl. Сколько граммов NaCl получилось?
NaOH + HCl → NaCl + H2O
n(NaOH) = 8 / 40 = 0,2 моль; n(HCl) = 3,65 / 36,5 = 0,1 моль. Коэффициенты равны 1, поэтому HCl в недостатке. n(NaCl) = 0,1 моль; m = 0,1 · 58,5 = 5,85 г. Останется 0,1 моль NaOH (4 г).

Нельзя сравнивать массы («8 г больше 3,65 г») — сравнивайте количества вещества с учётом коэффициентов. И ещё: если избыток сам может реагировать с продуктом (например, CO2 с избытком щёлочи), проверьте состав продукта.
Проверь себя. В примере выше какое из веществ, NaOH или HCl, осталось после реакции?

Ответ: NaOH

3.Выход продукта и примеси

Реально продукта обычно получается меньше, чем по уравнению (потери, обратимость реакции). Отношение практической массы к теоретической — выход η.

η = m(практ.) / m(теор.) · 100%
Чистое вещество: m(чист.) = m(образца) · (1 − ω(примесей))

Пример 1 (выход). Из 11,2 г железа получили 20,32 г FeCl2. Fe + 2HCl → FeCl2 + H2. n(Fe) = 0,2 моль; m(теор.) = 0,2 · 127 = 25,4 г. η = 20,32 / 25,4 = 0,8, то есть 80%.

Пример 2 (примеси). Известняк массой 250 г содержит 20% примесей. m(CaCO3) = 250 · 0,8 = 200 г = 2 моль. CaCO3 → CaO + CO2, n(CO2) = 2 моль, m = 88 г.

Выход применяют к продукту, а не к исходному веществу. И если задачу просят найти массу исходного вещества по практическому выходу, теоретическую массу продукта находят делением: m(теор.) = m(практ.) / η.
Проверь себя. Сколько граммов CO2 образуется при разложении 200 г чистого CaCO3?

Ответ: 88

4.Раствор после реакции

В задачах ЕГЭ №34 (и ОГЭ №22) часто просят найти массовую долю вещества в растворе после реакции. Массу нового раствора считают по закону сохранения массы.

m(р-ра после реакции) = m(исходного р-ра) + m(добавленного вещества) − m(↓) − m(↑)
ω(соли) = m(соли) / m(р-ра после реакции)

Пример. К 100 г 10% раствора NaOH добавили 100 г 7,3% раствора HCl. Найдите ω(NaCl).
m(NaOH) = 10 г → 0,25 моль; m(HCl) = 7,3 г → 0,2 моль. HCl в недостатке. n(NaCl) = 0,2 моль; m = 11,7 г. Газа и осадка нет, m(р-ра) = 200 г. ω(NaCl) = 11,7 / 200 = 5,85%. В растворе остался избыток NaOH (0,05 моль).

Если выделяется газ или осадок, их массы вычитают. Если растворяется твёрдое вещество (Zn в кислоте), его масса прибавляется, а масса водорода вычитается.

Не берите за массу нового раствора массу только одного из исходных растворов. И не забудьте, что вода в реакции может образовываться — она входит в массу раствора и отдельно её не прибавляют.
Проверь себя. Чему равна массовая доля NaCl (%) в растворе из примера выше?

Ответ: 5.85
