Моль, молярная масса и молярный объём газа

Базовые величины химических расчётов: количество вещества, масса, объём газа, число частиц, плотность и массовая доля элемента.

15 мин чтенияОГЭЕГЭ21 задание

Коротко

главное за 30 секунд
  1. n = m / M = V / Vm = N / NA — количество вещества связывает все величины
  2. M (г/моль) численно равна относительной молекулярной массе Mr
  3. При н. у. молярный объём газа Vm = 22,4 л/моль; NA = 6,02·1023 моль−1
  4. Относительная плотность газа: D = M1 / M2; M(воздуха) ≈ 29, M(H2) = 2
  5. Массовая доля элемента: ω(Э) = n · Ar(Э) / Mr(вещества)
  6. Объёмы газов в реакции относятся как коэффициенты (при одинаковых условиях)

1.Моль и число частиц

Моль — количество вещества, содержащее 6,02·1023 частиц (атомов, молекул, ионов). Это число — постоянная Авогадро NA. Молярная масса M — масса одного моля, в г/моль, численно равная Mr: M(H2O) = 18 г/моль, M(H2SO4) = 98 г/моль.

n = m / M = N / NA
m = n · M; N = n · NA

Пример. Сколько молекул в 9 г воды? n = 9 / 18 = 0,5 моль; N = 0,5 · 6,02·1023 = 3,01·1023 молекул. В этой порции 3,01·1023 · 3 = 9,03·1023 атомов.

Различайте «молекул» и «атомов». В 1 моль H2O — 6,02·1023 молекул, но 1,806·1024 атомов (3 атома в молекуле) и 1,204·1024 атомов водорода.
Проверь себя. Сколько моль составляют 49 г серной кислоты H2SO4?

Ответ: 0.5

2.Молярный объём газов и плотность

По закону Авогадро равные объёмы любых газов при одинаковых условиях содержат одинаковое число молекул. При нормальных условиях (0 °C, 101,3 кПа) 1 моль любого газа занимает 22,4 л.

n = V / Vm, V = n · 22,4 (л, н. у.)
Плотность газа ρ = M / 22,4 (г/л)
Относительная плотность D2(1) = M1 / M2

Пример. Плотность хлора по воздуху: D = 71 / 29 ≈ 2,45 — хлор тяжелее воздуха. Плотность водорода по воздуху 2 / 29 ≈ 0,07 — водород легче воздуха, его собирают вверх дном.

Средняя молярная масса смеси газов: Mср = (n1M1 + n2M2) / (n1 + n2), а для объёмных долей φ: Mср = φ1M1 + φ2M2.

22,4 л/моль — только при н. у. и только для газов. В воде, спирте и других жидкостях 1 моль занимает совсем другой объём. Не подставляйте 22,4 в расчёты по массе жидкостей.
Проверь себя. Чему равна молярная масса газа (г/моль), если 1 л его при н. у. имеет массу 1,964 г? Округлите до целых.

Ответ: 44

3.Массовая доля элемента и формула вещества

Массовая доля элемента показывает, какая часть массы вещества приходится на данный элемент: ω(Э) = n · Ar(Э) / Mr. Сумма долей всех элементов равна 100%.

Пример. ω(N) в аммиачной селитре NH4NO3: Mr = 80, азота 2 атома: ω = 2 · 14 / 80 = 0,35, то есть 35%.

Вывод формулы по массовым долям. Разделите массовую долю каждого элемента на его Ar, получите отношение чисел атомов, приведите к целым числам. Если известна M вещества, найдите истинную формулу.

Пример. Вещество: 40% C, 6,67% H, 53,33% O, M = 60 г/моль. C : H : O = 40/12 : 6,67/1 : 53,33/16 = 3,33 : 6,67 : 3,33 = 1 : 2 : 1 → CH2O (M = 30). Истинная формула: 60 / 30 = 2 → C2H4O2 (уксусная кислота).

Не забывайте умножать на число атомов (индекс). Частая ошибка: ω(H) в воде считают как 1 / 18, а нужно 2 / 18 = 11,1%.
Проверь себя. Чему равна массовая доля азота в NH4NO3 (в процентах)?

Ответ: 35

4.Алгоритм и типичные ошибки

  1. Запишите, что дано и что найти; переведите единицы (мл → л, кг → г).
  2. Найдите M нужных веществ по таблице Менделеева.
  3. Найдите количество вещества n (через массу, объём или число частиц).
  4. Через n найдите искомую величину.
  5. Проверьте размерность и здравый смысл ответа.
Молярную массу считайте по формуле «сумма Ar» с точностью до целых (Cl = 35,5 — исключение). В ОГЭ и ЕГЭ округляйте так, как указано в условии.
Типичные ошибки: путают массу (г) и молярную массу (г/моль); используют 22,4 л для не-н. у. условий; берут объём в мл вместо л; забывают, что в молекуле O2 два атома кислорода (M = 32, а не 16).
Проверь себя. Какой объём (л, н. у.) занимают 0,25 моль кислорода?

Ответ: 5.6
